# Student Hub v1.8.1

Randomizer + Monthly Cash Refinement

## Fokus
- Randomizer lebih deterministik secara UI dan aman terhadap duplikasi item.
- Penetapan ketua memerlukan konfirmasi setelah undian.
- Urutan presentasi dapat disusun satu per satu dan dijadwalkan ke kalender.
- Kas kelas ditata sebagai laporan per bulan tanpa membuat ledger ganda.
- Ringkasan iuran per periode ditampilkan bersama saldo bulanan.
- Security, CAPTCHA, MFA, dan Web Push dari v1.8.0 tetap dipertahankan.
