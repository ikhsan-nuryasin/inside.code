# Randomizer — v1.7.0

- Wheel renders only the remaining pool, so the pointer aligns with the actual candidate set after every spin.
- Presentation order removes each selected group until the sequence is complete.
- Group leader supports wheel and manual selection.
- Member random selects exactly one member per run.
- Presentation results can be saved and optionally scheduled as one calendar event per group with duration and gap.
- History remains class-scoped.
