## V1.4.1 — UI/UX Rework

# Student Hub v1.1.4 — Mobile Reference + Full Feature UI

The mobile interface follows the supplied Student Hub reference as the primary visual direction:

- white / very light blue surfaces
- vivid blue primary actions and class headers
- rounded cards with soft shadows
- compact mobile typography and spacing
- mobile bottom navigation: Home, Kelas, Tugas, Jadwal, Lainnya
- secondary modules exposed through Lainnya
- responsive desktop fallback using the same visual language
- authentication aligned to the same visual system

Feature-completeness hardening added in this release:
- task edit in addition to create/delete/checklist/progress
- schedule and subject edit/delete with lecturer, credits, and practical-group fields
- material edit in addition to create/delete/attachments
- group edit and group-task edit in addition to member management
- poll description and anonymous-voting fields

No attendance, class-create, class-join, or public member-directory features were added.
