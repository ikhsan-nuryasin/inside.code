# v1.8.1 — Randomizer + Kas Kelas Bulanan

## Randomizer
- Stable IDs are used for groups and members so duplicate display names cannot select the wrong record.
- Random index uses `crypto.getRandomValues` when available.
- Wheel draw is separated from leader assignment; setting a leader requires confirmation.
- Presentation ordering removes the selected group from the next pool.
- Presentation schedule is validated not to cross midnight.
- Calendar creation happens before the final history record is written.

## Kas Kelas
- One class cash ledger remains the source of truth.
- UI is scoped to a selected `YYYY-MM` period.
- Summary: opening balance, income, expense, net change, closing balance.
- Iuran and transactions are filtered to the selected month.
- Verified payments link to the ledger using `cash_transaction_id`.
- Migration 027 ensures empty months return a zero summary row instead of null.
