# Student Hub v1.4.2 — Class Detail UI

Perubahan mobile Detail Kelas dibuat mengikuti struktur visual referensi pengguna:
- header lokal ringkas;
- hero card biru berisi kode kelas, program studi, semester, dan tahun akademik;
- empat shortcut utama (Informasi Kelas, Mata Kuliah, Anggota Kelompok, Jabatan Kelas);
- daftar Mata Kuliah dengan row yang mudah disentuh;
- quick utilities untuk Tugas, Agenda, Randomizer, dan Kas;
- tombol Semua Fitur + bottom sheet untuk menjaga seluruh modul tetap mudah ditemukan.

Pada modul non-ringkasan, mobile menampilkan local module bar agar pengguna selalu punya jalur kembali ke Ringkasan dan akses cepat ke pemilih modul.
