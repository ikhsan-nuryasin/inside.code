# Student Hub v1.4.0 — Mobile UI/UX Refinement

## Fokus
- Menghapus global app header dari AppShell pada layout baru.
- Setiap halaman menggunakan local page chrome yang ringkas.
- Dashboard mobile memakai hero biru + white floating class card.
- Quick actions memakai circular icon treatment.
- Card, form, chips, buttons, empty state, notification popup, dan bottom navigation diseragamkan.
- Detail kelas memakai module launcher 2 kolom agar semua fitur tetap terlihat.
- Mobile bottom navigation tetap Home, Kelas, Tugas, Jadwal, Lainnya.
- Tidak menggunakan logo atau identitas visual resmi Livin by Mandiri; hanya mengadopsi pola hierarchy yang umum pada super-app modern.

## Product rules tetap
- Tidak ada absensi/presensi.
- Tidak ada role dosen.
- Tidak ada pembuatan kelas mandiri.
- Tidak ada join kelas mandiri.
