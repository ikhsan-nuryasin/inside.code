# Student Hub v1.3.0 — Connected UI/UX

## UX goal
Semua modul utama harus mudah ditemukan, tetap membawa konteks kelas aktif, dan memberikan umpan balik visual setelah aksi.

## Implemented
- Active class context disimpan di perangkat dan dipakai lintas modul.
- Workspace class membuka Tugas, Jadwal, Randomizer, Kas, Dokumentasi, Jabatan dalam konteks kelas yang sama.
- Class detail mobile memiliki quick-connect actions.
- Task inbox memiliki filter kelas.
- Calendar terhubung ke Randomizer dan Tugas.
- Notification center punya mark-all-read; popup tetap aktif.
- Reusable toast feedback untuk aksi sukses.
- Service worker cache dinaikkan ke v1.3.0.

Product rules tetap: tanpa absensi/presensi, tanpa role dosen, tanpa membuat kelas, tanpa self-join.
