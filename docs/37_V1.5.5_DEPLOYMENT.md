# v1.5.5 Deployment

The frontend is deployable as a static Vite site. Build `web/dist` and host that directory on a static HTTPS host. Supabase provides Auth, Postgres, Storage, and Realtime.

The release bundle includes:

- Vercel configuration
- Netlify configuration
- Cloudflare Pages instructions
- Apache `.htaccess`
- private-storage/RLS guidance
- PWA/service-worker setup
- production checklist

The application intentionally keeps class creation/joining and attendance out of the student client.
