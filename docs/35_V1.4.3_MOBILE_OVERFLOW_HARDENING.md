# v1.4.3 — Mobile Overflow Hardening

Focused pass to eliminate accidental horizontal overflow on narrow phones (including ~320–380px widths).

Changes:
- min-width:0 on nested flex/grid content
- safe wrapping for long titles, URLs, file names, notes, posts and labels
- action groups wrap/stack on narrow screens
- poll, finance, file and notification rows constrained to viewport
- randomizer wheel capped to viewport width
- class detail cards and feature sheet constrained
- bottom navigation tightened on <=380px
- vertical-only scrolling for mobile sheets
- service worker cache bumped to v1.4.3
