# Student Hub v1.2.0 — Productivity Upgrade

## UI / UX
- Mobile reference skin remains the visual source of truth.
- Notification Center remains available, while new notifications are surfaced as popup overlays.
- Popup preferences are configurable by notification type from Settings.
- Dashboard now prioritizes near-deadline tasks and recent class activity.

## Randomizer
- Ketua Kelompok.
- Urutan Presentasi.
- Random Anggota.
- Presentation order can be stored as a class event in Calendar.
- Saved randomizer history remains available.

## Calendar / Class Activity
- Unified calendar now combines schedules, task deadlines and class events.
- Class events include class, presentation, exam, meeting, task deadline, and other.
- Trusted activity timeline records important class mutations.
- Pinned class information is surfaced in the class overview.

## Polling / Decisions
- Polls can be marked as class decisions.
- Closed decision polls show the selected outcome.

## Cash
- Personal "Iuran saya" status is shown per due item.
- Existing payment proof, verification, rejected re-submit, partial, void and correction flows are preserved.

## Notifications
- Popup types: task, schedule, forum, material, announcement, cash, group, polling, documentation and system.
- Local deadline reminders can appear when the app is open and cached task data is available.
- Background push delivery is not claimed; server notification history remains the source of truth.

## Product freeze
- No attendance / presensi module.
- No lecturer module.
- No create-class flow.
- No join-class flow.
