# Student Hub v1.5.2 — Build Fix

Fixed the 29 TypeScript/compiler errors reported from the local v1.5.0 verification log.

## Fixed areas
- Demo-mode exports for `demoClassEvents` and `demoActivityLogs`.
- Null-safe Supabase realtime channel cleanup.
- Null-safe dashboard profile access.
- `ClassPage` overview quick actions now use `klass.id`.
- `RandomizerPage` wheel no longer references page-only `activeClass`.
- Removed obsolete `mode_placeholder` comparison.
- Service-worker cache version bumped to prevent stale JS/CSS after the fix.

## Verification
Run in `web`:

```powershell
npm install
npm run verify:buildfix
npm run typecheck
npm run build
npm run dev
```

The supplied local log shows `npm install` and `vite` development server startup succeeding, while `tsc -b` stopped on 29 TypeScript errors. This release addresses those reported compiler errors at source level.
