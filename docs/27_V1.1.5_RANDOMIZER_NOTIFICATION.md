# v1.1.5 — Randomizer & Notification Popup


- Added mobile-visible Randomizer page.
- Modes: Ketua Kelompok, Urutan Presentasi, Random Anggota.
- Presentation mode removes the selected group from the remaining wheel and produces final numeric presentation order.
- Leader mode uses existing group membership and persists the chosen leader through the existing RPC.
- Saved randomizer results persist to `randomizer_results` in Supabase when online.
- Added global unread/realtime notification popup. It auto-dismisses after 6.5 seconds and opens notification history when tapped.
- Mobile styling follows the supplied Student Hub reference: white/blue surface, rounded cards, soft shadows, compact controls, mobile bottom navigation.


## Superseded by v1.2.0
Randomizer now also integrates presentation order with Calendar, and popup notifications have per-type preferences.
