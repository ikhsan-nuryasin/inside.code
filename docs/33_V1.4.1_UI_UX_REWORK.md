# Student Hub v1.4.1 — UI/UX Rework

- Reworked mobile visual hierarchy for readability at real device size; previous micro-font sizing was reduced in favor of 9–14px secondary/body text and 18–22px screen titles.
- Removed persistent/global mobile header and kept screen-local titles only where needed.
- Dashboard now follows the supplied reference more closely: white greeting area, compact notification control, blue active-class card, circular quick actions, task/schedule cards, and bottom navigation.
- Replaced text glyph navigation with lightweight inline SVG icons.
- Standardized cards, fields, chips, badges, action buttons, lists, empty/error states, cash cards, randomizer, notifications, search, settings, and auth screens.
- Updated PWA service-worker cache namespace to v1.4.1 so stale CSS is invalidated on update.
- Application functionality and existing product rules are preserved.
