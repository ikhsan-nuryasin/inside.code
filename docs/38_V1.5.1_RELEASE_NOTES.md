# Student Hub v1.5.2 — Release Notes

## Purpose
A corrective release based directly on the local TypeScript/build log supplied with the project.

## Fixed
- Missing demo-mode symbols `demoClassEvents` and `demoActivityLogs` are present in the shipped `demo.ts`.
- Supabase realtime cleanup uses a non-null `client` captured after the availability guard.
- Dashboard profile lookup safely handles `null`.
- Class overview quick links use the in-scope `klass.id`.
- Randomizer wheel no longer references `activeClass` from the parent page.
- Obsolete `mode_placeholder` union comparison removed.
- Service-worker cache updated to `student-hub-v1.5.2-build-fixed`.
- Static/connected UX audits updated to recognize the current service-worker cache version.

npm install
