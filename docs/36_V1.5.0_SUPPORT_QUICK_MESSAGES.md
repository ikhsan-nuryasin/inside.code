# Student Hub v1.5.0 — Support & Quick Messages

## Bantuan
Pusat Bantuan tersedia setelah login dan berisi FAQ, panduan singkat, serta formulir laporan bug. Setiap laporan dikaitkan dengan `auth.uid()`/`profiles.id` dan secara otomatis merekam halaman serta user-agent.

## Laporan Bug
Field: judul, kategori, severity, deskripsi, langkah reproduksi, hasil yang diharapkan, hasil yang terjadi, dan halaman. Status awal `open`. RLS membuat pengguna hanya dapat membaca laporan miliknya sendiri dan hanya dapat membuat laporan atas nama dirinya sendiri.

## Pesan Cepat
Pesan Cepat menyediakan template WhatsApp: izin tidak masuk, izin terlambat, izin sakit, keperluan keluarga, kirim tugas, minta materi, konsultasi, konfirmasi jadwal/presentasi, dan pesan custom. Nomor dinormalisasi ke format internasional `62...` sebelum membuka `https://wa.me/...`.

Pengiriman pesan tetap dilakukan oleh aplikasi WhatsApp pengguna. Student Hub hanya menyiapkan URL dan teks.

## Login
Aplikasi production mewajibkan session Supabase aktif sebelum merender workspace utama. Logout tetap membersihkan local cache/outbox seperti pada versi sebelumnya.
