# v1.0.7 — Tidak Ada Absensi

## Keputusan Produk
Student Hub tidak menyediakan fitur absensi apa pun.

### Dihapus
- Menu Absensi
- Halaman Absensi
- Route Absensi
- Capability `manage_attendance`
- Model `AttendanceSession` dan `AttendanceRecord`
- Demo data absensi
- Repository functions absensi
- Database table `attendance_sessions`
- Database table `attendance_records`
- Database enum `attendance_status`
- Database RPC absensi
- RLS policy absensi

### Bukan bagian aplikasi
Presensi resmi kampus tetap dilakukan melalui web resmi kampus. Student Hub tidak menduplikasi, menyimpan, atau mengelola data presensi kampus.

### Dampak Role
- Ketua/Wakil: tidak memiliki tugas absensi.
- Sekretaris: tidak memiliki tugas absensi.
- Bendahara: tidak memiliki tugas absensi.
- Anggota: tidak memiliki status absensi di Student Hub.
